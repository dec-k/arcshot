## Arcshot
Arcshot is a tiny Firefox plugin for taking fancy screenshots.

Its intent is to emulate the style of screenshots generated by [Arc Browser](https://arc.net/), which has more-or-less ceased development.

### Current Features
* Standard 'screenshot' functionalities like saving as .PNG or copying to clipboard.
* Screenshots taken are configurable with a user-specified background.

### Planned Features
* Localisation support.
* Configurable Watermark or branding.
* Popout widget instead of full-tab display.

### Contributing
If you want to contribute to Arcshot, feel free to raise pull requests or report bugs, and I will do my best to answer every item.

### Developing Locally
* Visit `about:debugging` in Firefox
* Select 'Load Temporary Addon'
* Select the `manifest.json` file from this repository.
