## Arcshot
Arcshot is a tiny browser plugin that automates adding a little extra panache to your screen-grabs by adding customisable frames and backgrounds to every capture.

Arcshot does not 'phone home' or store any data. All captures taken are only copied to your clipboard, or saved to your local machine.

Arcshot is available for download from addon stores:
* [Arcshot for Firefox](https://addons.mozilla.org/en-US/firefox/addon/arcshot/)

### Current Features
* Simple pop-out interface to
* Automatically edit captures with stylistic backgrounds, gradients, and frames.

### Install or Develop Locally
**Firefox**
* Visit `about:debugging` in Firefox
* Select 'Load Temporary Addon'
* Select the `manifest.json` file from this repository.
